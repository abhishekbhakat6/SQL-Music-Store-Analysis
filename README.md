# SQL Music Store Database Analysis 🎵

## 📌 Overview  
This project explores a music store database using **postgreSQL**, extracting key insights about sales, customers, and music trends.

## 🔍 Key Analysis  
✔️ Total sales and revenue trends  
✔️ Customer purchase behavior  
✔️ Best-selling genres and artists  
✔️ Employee sales performance  

## 🛠️ Technologies Used   
- PostgreSQL  
- Data Analysis  

## 📂 Files  
- `Music_Store_database.sql` – Database schema and queries  

## 🚀 How to Use  
1. Import `Music_Store_database.sql` into your SQL environment.  
2. Run queries to analyze sales trends, customer data, and music preferences.
